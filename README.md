# StudyGame

لعبة ألغاز ومسابقات للأولاد من كتبهم المدرسية (Godot 4.7، أندرويد).

- كل ولد له ملف: يختار اسمه، ويطلع له بس كتب صفه.
- كل كتاب خريطة: وحدات ودروس، وكل درس جولة من 8 أسئلة (اختيار من متعدد، صح وخطأ، وصّل، رتّب).
- الصغار (حتى الصف الخامس) يكشفون صورة مخفية مع كل إجابة صح، والكبار يفتحون قفل بالأرقام.
- الأسئلة الغلط تنحفظ في "راجع أخطائك".

## تنزيل النسخة على الجوال

كل دفعة على `main` تبني APK وتنشره في الـ Release اسمه **latest** (من صفحة الريبو ← Releases).
وكل دفعة على أي فرع ترفع الـ APK كـ artifact في صفحة Actions.

## Development

- Godot 4.7, GDScript, portrait 1080×1920. Screens build their nodes in code (`scripts/ui/`).
- Books live in `data/books/<id>.json` (listed in `data/books/index.json`). They are generated by
  `tools/content/<id>.py`; edit the script, run it, commit both.
- The source PDFs are in `Books/` (ignored by Godot via `.gdignore`, never exported).
- Reward pictures come from Higgsfield: `tools/fetch_art.sh` downloads them to `assets/rewards/`.
  Without them the game draws a simple landscape.
- Tests: `godot --headless --path . --import` then `godot --headless --path . res://tests/test_runner.tscn`.
- Screenshots: `xvfb-run -s "-screen 0 1080x1920x24" godot --path . --rendering-driver opengl3 res://tools/screenshot.tscn -- quiz out.png nada g3_science`.
